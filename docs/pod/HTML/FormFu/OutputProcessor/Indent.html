NAME

HTML::FormFu::OutputProcessor::Indent - Nicely Indent HTML Output

VERSION

version 2.09

SYNOPSIS

    ---
    output_processors:
      - Indent

METHODS

indent

Arguments: $string

Default Value: "\t"

The string to be used to indent the HTML.

preserve_tags

Arguments: \@tags

Default Value: ['pre', 'textarea']

An arrayref of tag names who's contents should not be processed.
