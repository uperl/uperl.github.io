NAME

HTML::FormFu::Transformer::Callback - Callback transformer

VERSION

version 2.09

SYNOPSIS

    $field->transformer('Callback')->callback( \&my_transformer );

    ---
    elements:
      - type: Text
        name: foo
        transformers:
          - type: Callback
            callback: "main::my_transformer"

DESCRIPTION

The first argument passed to the callback is the submitted value for the associated field. The second argument passed to the callback is a hashref of name/value pairs for all input fields.

METHODS

callback

Arguments: \&code-reference

Arguments: "subroutine-name"
